|---|---|---:|---:|---|
| 桌面基线 | UnityMain:-1,UnityGfxDevice:-1 | 0 | 0 | 无 |

10206和9830都名为GameThread，Tgid均为9326。RenderThread11148也属于9326，
不是其它应用的线程。PID变化不能单独当作CTN下发错误。

本次读取到 `htb_strategy=0`、`target_fps=30`、`expire_time_percentage=80`。
**target_fps是节点配置值，不是测出的实际FPS**，本轮未测帧率或功耗收益。

退出后的约18秒八次采样，均确认原名单、两个开关0、债务不存在，未反复覆盖。
最终只读自检与服务／daemon身份检查返回0；没有exercise.state或.service.stop残留。

## 操作和范围

本轮只正常启动三角洲、按HOME退出，以及只读采集节点／线程／日志。
没有写CHTB／CTB开关、COSA库、game_pid、rt_info或CTN；没有运行写入自检，
没有停启CTNP服务、加载／卸载KO或重启手机。退出后的开关变化由系统自动完成。

本轮只验证大厅和进退状态，未进入或操控正式对局，未确认FPS／功耗提升、全部游戏
阶段、141对应设备或先前告警的因果关系。无需制造无依据的CTNP补丁。
