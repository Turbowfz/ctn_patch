## 自动下发与恢复

只读查询真实COSA数据库的稳定DB/WAL副本，和平精英配置为
`ctn="RenderThread Thread-"`，与实际节点一致；未改数据库、game_pid或rt_info。

```text
进入前：game_pid=-1，UnityMain:-1,UnityGfxDevice:-1
启动后：game_pid=32318，RenderThread:-1,Thread-:-1
退出后：game_pid=-1，UnityMain:-1,UnityGfxDevice:-1
```

生产日志和内核独立证据：

```text
[11-15 08:57:04] ctnd: critical_task_name applied [RenderThread Thread-]
[11-15 08:59:02] ctnd: critical_task_name restored
[32843.444215] ctn_patch: names [RenderThread:-1] [Thread-:-1]
[32961.268682] ctn_patch: names [UnityMain:-1] [UnityGfxDevice:-1]
```

游戏停在“用户协议及隐私保护指引”，没有替用户同意协议、登录或进入对局。
所以本轮证明**真实应用启动下发与离开后恢复**，不是完整对局／帧率／功耗验收。
这阶段两个目标线程都未匹配到有效HAL登记PID，显示-1；不能声称线程匹配／调度收益完成。
`ct_enable`进入时1、退出0为系统／HAL变化，CTNP仍不默认代管该节点。
