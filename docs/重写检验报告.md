## 本轮关键修复

- 按 profile 独立构建和隔离输出，不再修改 141 的版本字符串冒充 157。
- 内核动态函数在首次间接调用前检查 KCFI；缺安全读取能力拒绝，不退回裸 memcpy。
- 目标模块引用、对象尺寸、内存区域和原值检查；PID 只在锁与 RCU 保护下核对初始 PID 命名空间任务身份。
- 应用值仅在写入成功后提交；恢复失败保留债务，读库/SQL 失败不当作配置删除。
- 修复首次查询指纹未初始化、跨包/同尺寸更新、半绑定 SQLite 句柄、退出防抖累计错误。
- 修复重启偿债后首次 PID 清掉 HAL 让权，以及跨游戏旧观察值导致误拒绝下发。
- 实际持有共享锁后回收仅属于自身的已知崩溃快照；未知文件、权限异常和链接完整保留。
- 保留禁用/删除状态，文件与正在运行的身份分开报告，不以旧 KO 可运行证明新 KO。
- 修复 mksh 列表分隔解析：`|` 必须在 shell 参数模式中转义；在 Debian mksh 与实际 Android shell 复测。
- 修复构建身份递归计入生成物、遗漏 Kbuild，以及布局大小与同名字段偏移记录碰撞。
