## 本版内容

- 版本 **v3.1 / versionCode 31**，模块 ID 保持 `ctn_patch`。
- 不创建、读取或支持 `ctn.conf` 手动配置；CTN 自动从 COSA 数据库读取。
- 自检给用户的是简短中文适配、运行与收尾状态；详细信息单独保存在
  `/data/adb/ctn_patch/action-detail.log`，摘要是 `action.log`。
- 安装检查由 Root 管理器输出／保存，不额外创建安装日志。
- 开机先按 6.1.141 / 6.1.157 选择对应 KO，再核验完整内核 release、厂商 game_opt 和
  文件身份；不要求手选、不轮流试载、不以只比版本号替代 ABI 检查。
- `changelog.txt` 包含 v1.0 到 v3.1 共 **15 个版本**，每版最多四条短要点；安装只显示当前版。
  更新弹窗的 `update-changelog.md` 也只有当前版。详细历史仍可从 Git 历史读取。
- 模块横幅使用 `banner=oplus.png`。原图 1234×694；仅去掉 PNG IEND 后 2750 字节编辑器
  数据，逐像素校对一致，桌面原件不改。支持 banner 的管理器显示，不支持者忽略。

## 手机与第三方刷写边界

手机仍运行已安装的 **v3.0**，没有为了本版检查安装、停止服务、写节点或重启。唯一临时
目录运行 v3.1 默认 verify：

```text
[正常] 文件与兼容性：内核 6.1.157，对应 KO 与厂商组件匹配
[失败] 当前运行：v3.0；身份不同或未知，请正常重启后再自检，不会自动启用
```

默认输出八行中文，没有完整哈希／技术 dump；`--details` 输出完整信息。两种模式真实
远端退出码都为 1，正确拒绝将磁盘新包当成已运行新版。对 KernelSU BusyBox standalone
实际初始化与选择的只读探测返回 0。原始证据在 `out/v3.1-20261114/phone-readonly/`。

此前确认的第三方同类报错是 BusyBox 返回裸 `sh` 造成的初始化失败，3.1 保留绝对路径修复，
并直接向管理器显示具体原因及处理提示。没有其它失败用户的完整固件和日志，不宣称
未知设备一律能刷；完整 release 或 vendor SHA 不匹配时仍安全拒绝，需要另取设备基线。

**未实机完成：**v3.1 新 KO 的加载／写读／卸载、141 对应实机、本版真实游戏收益和 banner
实际管理器显示。v3.0 的157真实游戏下发与退出恢复是历史证据，不替代本版新产物。
因此本包继续带 DEVELOPMENT 标记，发布时不冒称双版本实机认证。
